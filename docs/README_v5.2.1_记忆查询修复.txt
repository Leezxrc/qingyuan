清渊 v5.2.1：Memory Query Hotfix
============================================================

修复问题：

用户先说：
“记住，我微信的家庭群名字是9652711”

清渊成功保存：
家庭群 = 9652711

随后用户问：
“我的微信家庭群叫什么”

旧版本因为看到“微信”，可能误路由到 GUI，
导致申请：

键盘
鼠标
读取屏幕
控制窗口

这是错误行为。


v5.2.1 改为：

已知关系查询
    ↓
优先读取 data\knowledge
    ↓
直接回答
    ↓
不进入 GUI Router
    ↓
不申请 Task Permit


支持示例：

家庭群叫什么？
家庭群叫啥？
家庭群是哪个？
家庭群名字是什么？
你还记得家庭群吗？
我的微信家庭群叫什么？


正常输出类似：

[长期记忆] 本地读取，无需电脑操作权限。
清渊：我记得，你的“家庭群”对应微信聊天“9652711”。


另外：

Router 中记忆查询优先级提高，
“微信”本身不再足以让一个明显的记忆问题变成 GUI 操作。
