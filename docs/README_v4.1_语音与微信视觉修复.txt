清渊 v4.1 修复
==================================

1. 修复待机后“🎤 清渊正在听……”高速刷屏
   根因不是 VAD，而是 Agent 的 HTTP /listen 客户端 45 秒超时。
   STT 服务端仍在占用麦克风监听，Agent 却开始不断重连并收到 409。
   现在监听请求最长等待改为 3600 秒，并增加 250ms 空结果退避。

2. 修复“把微信调到前台”被当成完整 GUI 任务
   新增：
   调到前台 / 调到最前 / 切过去 / 调出来
   → foreground intent
   只申请窗口相关权限。

3. 微信视觉定位改为“授权目标窗口内定位”
   以前 Qwen3-VL 看整个多屏桌面，容易把搜索框点到别处，
   之后 keyboard_type 就会报告微信已不在前台。

   现在：
   - 获取当前任务 target HWND
   - GetWindowRect 获取微信真实窗口范围
   - 只把微信窗口 crop 送给 Qwen3-VL
   - VLM 坐标映射回该窗口的真实屏幕坐标
   - 坐标不在授权窗口内则直接拒绝点击
   - 如果同一授权窗口意外失焦，会先尝试恢复同一 HWND

4. 保留之前的 Task Permit / Planner / Executor / Verifier / 自回声过滤。
