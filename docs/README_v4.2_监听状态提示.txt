清渊 v4.2：监听状态提示优化
==================================

原来：
每次 STT /listen 请求都会打印：
🎤 清渊正在听……
所以服务重连或监听重新开始时会重复刷屏。

现在：
1. 每个等待周期只显示一次：
   🎤 清渊正在听……

2. 收到用户语音/键盘输入后，
   下一次等待新命令时可以再次显示一次“正在听”。

3. 连续 45 秒没有有效活动后只显示一次：
   🌙 清渊休息啦。

4. 进入休息状态以后不会继续刷“正在听”。

5. “清渊休息啦”只打印，不自动 TTS 朗读。

其他 v4.1 功能全部保留：
- Task Permit
- Planner / Executor / Verifier
- Chrome
- 微信窗口内视觉定位
- 自回声过滤
- STT 词库
- 待机监听防高速重连
