清渊 v5.3.1：Teach / Execute Split
============================================================

修复两个关键问题。


一、教学内容不再被当成执行命令

例如：

“搜索的时候不要加上微信群，
微信群默认是微信的群聊，不包括在名字内。”

这是：
教学 / 纠正规则

不是：
现在去操作微信


v5.3.1 增加：

TeachExecuteClassifier

流程：

用户输入
    ↓
Teach / Execute 判断
    ↓
teach
    -> 保存经验规则
    -> 不进入 Router
    -> 不申请 Task Permit
    -> 不操作电脑

execute
    -> 正常 Router / Planner / Permit


教学日志：

[经验学习] 这是教学/纠正规则，不会执行电脑操作。


二、微信群名字标准化

之前：

“微信群9652711是我的家庭群”

可能保存成：

家庭群 = 微信群9652711

后续内部展开成：

微信群聊微信群9652711

这是错误的。


现在 wechat_chat 只存真正聊天名称：

微信群9652711
    -> 9652711

微信群聊9652711
    -> 9652711

群聊9652711
    -> 9652711

微信聊天9652711
    -> 9652711


因此：

家庭群
    ->
微信群聊9652711

不会重复前缀。


三、旧记忆兼容

即使 data\knowledge 中以前已经存成：

微信群9652711

resolve 时也会自动清理前缀。

所以不需要覆盖或删除你的 memory 数据。


四、经验规则会参与后续任务

例如你教：

“搜索微信群时不要带‘微信群’前缀，
只搜索真正的群名字。”

这条会进入 preferences 中，
类型：

instruction_rule

以后微信搜索相关任务会优先检索这条规则，
供 Planner / Agent Core 参考。


五、安全

教学规则：
不授予权限。

学会“微信搜索只用群名”
≠
可以自己操作微信。

执行仍然必须 Task Permit。
