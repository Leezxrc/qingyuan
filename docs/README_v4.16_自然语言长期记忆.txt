清渊 v4.16：Natural Language Long-Term Memory
================================================

以后不需要修改 Python 才能新增关系。

直接对清渊说：

记住家庭群就是微信群聊9652711

清渊会写入本地长期知识库。

之后可以说：

在家庭群里发送“我晚点回来”

内部会自动解析：

家庭群
  ->
微信群聊9652711

Task Permit 显示的仍然是用户原始命令。


支持的自然语言：

1. 新增

记住家庭群就是微信群聊9652711
记住我的默认浏览器是 Chrome
记住下载目录是 D:\Downloads

2. 修改

把家庭群改成微信群聊888888
把下载目录改成 D:\NewDownloads

3. 查询

家庭群是哪个？
你记得我的下载目录是什么？

4. 删除

忘记家庭群
不要再记下载目录


本地文件：

C:\MyAgent\data\knowledge\

entities.json
    人、群聊、软件实体、别名等

preferences.json
    默认浏览器、常用选择等

locations.json
    文件夹和路径

general.json
    其他普通长期关系


安全规则：

“记住……”本身视为明确允许写入
清渊自己的长期记忆库，因此不再二次确认。

但长期记忆不会授予电脑权限。

例如：

在家庭群里发送消息

仍然必须经过 Task Permit。

密码、API Key、私钥、银行卡等敏感内容
默认拒绝明文长期保存。
